When parsing relatively small files, it easily fits in memory. So we can parse the whole file altogether like what I did using pandas and the computer won't have anytrouble in loading the data. This way is very simple and easy to do.

Meanwhile if we have a large file, we would need to manage our memory usage better. Like the example for a ~341MB file when loading it into the memory using pandas it consumes just over 1,5GB of memory. If there are multipler users or concurrent operations the computer/server will run out of memory to use and potentially crash. To prevent this we can split the data into chunks to load 1 piece at a time so memory usage will be minimal. WE can also combine using memory optimization techniques to minimize unnecessary memory usage when parsing the data.

Note: we could also use other libraries that are more efficient in parsing large files like csv or polars library. Since we still want to do EDA and gain insight from the data. Pandas is the easiest libray to the EDA part thats why I didn't choose other libraries for this task
